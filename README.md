# Reproducibility Package for Inter2US

This repository provides the data, experimental setup, and evaluation scripts used in the paper:

> **Automatic Alignment between Elicitation Interviews and Requirements**

---

## Repository Structure
```
├── data_annotation/               # Inter-annotator agreement data (Sect. V)
├── data/
│   ├── public_interview/          # Publicly released interview dataset
│   ├── public_system_desc/        # Publicly released system description dataset
│   └── generated_US_unbound_limit/# User stories generated by LLMs for 15 private datasets
│                                  #   (includes generation prompt: system_prompt.txt, user_prompt.txt)
│
├── eval/
│   ├── pairwise_alignment_quality/        # Pairwise alignment quality (Sect. VI-A, Table III)
│   ├── text2stories_metric/               # Correctness and coverage evaluation (Sect. VI-B)
│   ├── blocking_operator/                 # Blocking operator efficiency (Sect. VI-C, Fig. 6)
│   └── ablation_chunking_alignment_quality/ # Chunking vs. full-context ablation (Sect. VI-D, Table IV)
│
├── train/                          # Training scripts for embedding models (blocking operator, Sect. VI-C)
└── README.md
```

---

## Data

The `data/` folder contains:

- `public_interview/`: Publicly released interview dataset used in our experiments.
- `public_system_desc/`: Publicly released system description dataset used in our experiments.
- `generated_US_unbound_limit/`: User stories generated using LLMs for **15 non-public datasets**. The original datasets are not shareable due to privacy restrictions. This folder also contains the generation prompts (`system_prompt.txt`, `user_prompt.txt`) referenced in the paper.

Each public dataset folder contains:
- `all_pairs_annotated.csv`: Annotated chunk-story pairs (ground truth for Sect. VI-A)
- `chunks_turns_3s1.csv`: Interview chunks (3-turn sliding window, stride 1)
- `user_stories.csv`: User stories
- `system_prompt_v1_final_metric.txt`: Full system prompt for the LLM-based judge matcher (Fig. 3 in the paper)

---

## Experiments

The `eval/` folder contains the scripts for all experiments from **Section VI** of the paper:

1. **Pairwise Alignment Quality** (Sect. VI-A):
   - Evaluates bi-encoders, cross-encoders, and LLM judges on annotated datasets.

2. **Correctness and Coverage** (Sect. VI-B):
   - Computes the Inter2US metrics over the 15 student projects.

3. **Blocking Operator Efficiency** (Sect. VI-C):
   - Benchmarks the embedding-based blocking operator (recall vs. token cost).

4. **Chunking vs. Full Context** (Sect. VI-D):
   - Ablation comparing pairwise matching with full-context evaluation.
